# **App Name**: Nik Finance

## Core Features:

- Live Dashboard Overview: Visual summary of balance, monthly spending, and recent activity using dummy data.
- Intuitive Bottom Navigation: A sticky mobile-first navigation bar providing instant access to Dashboard, Add Entry, Transactions, Analytics, and Settings.
- Smart Add Entry Form: A quick-action interface to input expenses and income categories effortlessly.
- Historical Transaction Ledger: A clean list of previous expenditures with clear categorization and iconography.
- AI Insight Tool: Uses a tool to analyze the current list of transactions and generate conversational tips on potential savings or anomalies in spending habits.
- Interactive Spending Charts: Beautifully rendered charts that visually break down expenses by category for quick financial review.
- Profile & App Settings: Management of user preferences and notification settings with a consistent fintech design.

## Style Guidelines:

- A sophisticated dark mode palette using an Ultra-Violet Indigo (#4242E6) as the primary brand color to evoke a sense of digital security and precision.
- The background uses a deep, midnight navy (#0B0C11) to create high contrast with the primary elements and improve focus on financial data.
- An electric cyan accent (#00E5FF) is used sparingly for call-to-action buttons and successful transaction states to ensure visual hierarchy.
- A single-font approach using 'Inter' (sans-serif) to maintain a modern, machined, and highly readable look suitable for numerical financial data across mobile devices.
- Linear, minimalist icons with slightly rounded corners, styled in a subtle monochrome stroke with a slight glow effect on the active bottom navigation tab.
- Mobile-first, card-based layout with generous padding and vertical rhythm to ensure complex financial data remains accessible on small screens.
- Micro-interactions on buttons and smooth horizontal slides between dashboard views to enhance the premium agency-grade app feel.
